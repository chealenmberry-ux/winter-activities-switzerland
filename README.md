# winter-activities-switzerland
Code Developed by Chealen Berry, Vicki Hrap, and Hillary Raiser

This project develops a website that allows the user to input preferences for winter activities in Switzerland, and outputs the top three recommendations for the user based on a variety of factors, such as weather and location.
