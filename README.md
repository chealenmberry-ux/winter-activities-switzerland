# winter-activities-switzerland
Code Developed by Chealen Berry, Vicki Hrap, and Hillary Raiser

**Swiss Winter Activity Finder:**
This project develops a website that allows the user to input preferences for winter activities in Switzerland, and outputs the top three recommendations for the user based on a variety of factors.

**Project features:**
Upon opening the website, the user is immediately introduced to a usable, interactive interface. On the left of the screen, all possible winter activities are displayed and start off as automatically selected. These options are: ice skating, snowshoeing, and winter hiking. The user can choose to eliminate certain options based on their activity preferences.
Once the user identifies their desired winter activities, they can indicate the price (in CHF) that they are willing to pay for this activity. The user can also indicate whether the weather conditions should be considered in the recommendation produced, and they can indicate if they would like to be given the après-ski options closest to their suggested outputs.
As the user updates their preferences, the website automatically updates in real time. The top three recommended winter activities (and the closest après ski locations, if requested) are then displayed on the screen for the user. The activity is described in detail for the user based on its title, activity type, difficulty level, the expected commitment of the activity (such as the length of the hike or duration of the activity), and the snow and sun conditions expected.


**Technologies used:**
